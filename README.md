# HPLGAME — کارگاه بازی‌سازی

یک وب‌اپ استاتیک فارسی و راست‌به‌چپ که بر اساس طرح فایل `Untitled4.pdf` ساخته شده است.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید یا داخل همین پوشه یک سرور استاتیک اجرا کنید:

```bash
python -m http.server 4173
```

سپس به `http://localhost:4173` بروید.

## امکانات

- داشبورد خانه، مسیر یادگیری، پیشرفت، ویترین، مربی و اشتراک
- ویرایشگر بلوکی و ویرایشگر JavaScript برای بازی «سفر ستاره»
- اجرای پیش‌نمایش بازی، امتیازدهی و آزمون ارتفاع پرش
- حالت موفق و خطا با پیام‌های مربی
- ذخیرهٔ خودکار تنظیمات در `localStorage`
- پنجرهٔ انتخاب دسترسی و انتشار نمایشی
- طراحی واکنش‌گرا برای موبایل

این نسخه بدون بک‌اند ساخته شده است؛ پرداخت، حساب کاربری، بررسی انتشار و مربی آنلاین در این نمونه رابط نمایشی هستند.
