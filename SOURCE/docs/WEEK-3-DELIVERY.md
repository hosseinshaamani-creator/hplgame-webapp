# تحویل اصلاح‌شدهٔ هفتهٔ سوم — ۳۰ اکتبر ۲۰۲۶

## تغییرات

- `lib/prototype.js`: مودال دو تب ورود/ثبت‌نام با ایمیل/رمز، حساب‌های محلی مستقل، جلسهٔ پایدار، سهمیهٔ بازی اول، پرمیوم آزمایشی، چت سه‌گام و بوم مخصوص دوز/مار/فلپی/ستاره‌ها.
- `app.js`: نام و وضعیت در هدر/سایدبار، ثبت مستقیم ایده، اتصال لینک‌ها و دکمهٔ هوپی به کارگاه در نسخهٔ بدون backend؛ Auth سروری پیکربندی‌شده حفظ شده است.
- `lib/discovery.js`: فرم و پیشنهادها مستقیماً به مربی متصل‌اند. مسیر و پژوهش قبلی قابل دسترسی باقی‌اند.
- `prototype.css`: مربی و بوم کنار هم، مودال‌ها، نشان‌های پرو، موبایل و تم‌های موجود.
- `tests/prototype.test.mjs`: هفت سناریوی رفتاری حساب، سهمیه، چت، سه بوم و خطاهای storage.
- `tests/demo-ui.test.mjs`: تست یکپارچهٔ پوستهٔ واقعی بدون backend، از ثبت‌نام تا بازی دوم و خروج.
- `docs/architecture.md` و `README.md`: قرارداد داده، مهاجرت، امنیت، نگهداری و محدودیت‌ها به‌روز شدند.
- فایل‌های ساخته‌شدهٔ ریشه `app.js`، `index.html` و `prototype.css`: از بیلد نهایی همگام می‌شوند.

## چک‌لیست پذیرش

| مورد | بررسی |
|---|---|
| Auth Modal | تب‌ها، خطای نام/ایمیل/رمز/تکرار، ایمیل تکراری، رمز اشتباه، ورود موفق، نمایش نام، reload، خروج و حساب مستقل |
| ایده | متن و هر سه پیشنهاد → مستقیم مربی؛ ایده اولین پیام است؛ ورودی HTML اجرا نمی‌شود؛ ایدهٔ دوم رایگان پروژه را بازنویسی نمی‌کند |
| مربی | گام بعد، کد، سؤال و پیام آزاد پاسخ متناسب می‌دهند؛ پیشرفت تا ۳ محدود و ذخیره می‌شود |
| Sandbox | بوم کنار مربی؛ دوز با کلیک و خانهٔ پر/برد، مار با رشد/برخورد/برد، فلپی با کلیک/کلید/مانع/پایان؛ restart واقعی |
| Paywall | ساخت دوم بلافاصله پنجره باز می‌کند؛ بدون ارتقا پروژه ایجاد نمی‌شود؛ ارتقای تستی واقعاً چندپروژه‌ای را باز می‌کند |
| دسترس‌پذیری | عنوان، inert پشت مودال، فوکوس، Tab trap، Escape، بازگشت فوکوس |
| حفظ تجربه | رنگ‌ها، Vazirmatn، RTL، هوپی، سایدبار، تم پایدار و تست‌های هفته‌های قبلی |
| امنیت نمونه | عدم ذخیرهٔ رمز خام؛ export بدون حساب/رمز؛ دادهٔ خراب/منقضی/مسدود؛ عدم اجرای ورودی و عدم افزودن کلید |

تست‌ها: `npm test` شامل ۲۶ تست (۱۸ قبلی + ۸ تست جدید/بازنویسی‌شده). تست واقعی PostgreSQL/RLS و ورود Supabase قبلی هم جزو مجموعه‌اند. تست مرورگر محلی: ثبت‌نام، نام هدر، پیشنهاد مار، پاسخ کد، حفظ مختصات بوم هنگام چت، paywall، فعال‌سازی پرو و ساخت فلپی بررسی شده‌اند. نتیجهٔ نهایی تست/build و انتشار در گزارش همراه کامیت ارائه می‌شود؛ صرف داشتن تست به معنی تضمین نبود باگ نیست.

## بیلد و مشاهدهٔ محلی

Node سازگار با `package.json`، از ریشهٔ مخزن:

```powershell
cd SOURCE
npm ci
npm test
npm run build
npm run preview
```

نشانی پیش‌فرض `http://127.0.0.1:4181/hplgame-webapp/` است. برای پورت دیگر `$env:PORT='4184'` تنظیم کن. در خانه ایده را بفرست یا یک پیشنهاد بزن؛ مربی و بوم مستقیم باز می‌شوند. برای تست Auth، ورود هدر یا «ورود به کارگاه آزمایشی» و تب ثبت‌نام را انتخاب کن؛ از ایمیل و رمز مخصوص تست استفاده کن.

## کامیت و استقرار GitHub Pages

پس از build، همگام‌سازی فایل‌های مستقل ریشه اختیاری است؛ workflow مستقیماً SOURCE را بیلد می‌کند:

```powershell
Copy-Item dist/app.js,dist/index.html,dist/prototype.css .. -Force
cd ..
git diff --check
git add SOURCE app.js index.html prototype.css
git commit -m "fix: complete week-three auth tutor sandbox and premium flow"
git push origin main
```

حساب Git باید دسترسی نوشتن به `hosseinshaamani-creator/hplgame-webapp` داشته باشد. Pages روی GitHub Actions تنظیم شده است. workflow `.github/workflows/pages.yml` پس از push به main، `npm ci`، تست و build را در SOURCE اجرا می‌کند و `SOURCE/dist` را با Pages منتشر می‌کند. در Actions موفقیت هر دو workflow و job deploy را بررسی کن؛ سپس سایت `https://hosseinshaamani-creator.github.io/hplgame-webapp/` را باز کن. hash محتوای assetها در index مانع کش نسخهٔ قبلی می‌شود.

## محدوده

Auth و اشتراک محلی آزمایشی‌اند؛ صاحب دستگاه می‌تواند storage را تغییر دهد. مربی پاسخ‌های شبیه‌سازی‌شده دارد. بوم‌ها templateهای اجرایی آموزشی‌اند؛ فلپی نمونهٔ شبکه‌ای گام‌به‌گام است و AI هر ایدهٔ دلخواه را به بازی کامل تبدیل نمی‌کند. پرداخت و AI آنلاین فعال نشده‌اند. این محدودیت‌ها در رابط هم بیان شده‌اند؛ دکمهٔ ارتقا پرداختی انجام نمی‌دهد.
