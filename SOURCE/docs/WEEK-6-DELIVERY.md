# فاز دوم، هفتهٔ ششم — خانه و انتخاب مسیر یادگیری

تاریخ بررسی: ۲۷ نوامبر ۲۰۲۶. بازهٔ رودمپ: ۶ تا ۱۲ آذر. این تحویل شامل خانهٔ شخصی، انتخاب مسیر، فرم ایده و ساده‌سازی رابط است.

## تغییرات رابط

- برچسب‌های تزئینی رنگی از لندینگ، مربی، پیش‌نمایش، حساب و پنجره‌ها حذف شدند؛ اطلاعات ضروری ذخیره، خطا و محدودیت اشتراک به صورت متن معمولی باقی مانده‌اند.
- ناوبری دسکتاپ و موبایل چهار مقصد دارد: خانه، مسیر یادگیری، بازی‌های من و حساب من. بازخورد و حریم خصوصی در فوتر هستند.
- صفحهٔ نخست مهمان بر ایده و دکمهٔ شروع تمرکز دارد. تنظیم زمان و سطح اختیاری و جمع‌شونده است.
- خانهٔ عضو نام کاربر، پروژهٔ جاری، قدم بعدی و پیشرفت واقعی را نشان می‌دهد. آمار ساختگی یا امتیاز تخمینی ندارد. تمرین حرکت/پرش ذخیره‌شدهٔ قبلی نیز قابل ادامه است.
- پنج مسیر دوز، مار، فلپی برد، پازل اعداد و جمع‌آوری ستاره در صفحهٔ مسیر یادگیری قابل انتخاب‌اند. انتخاب فقط پیش‌نویس فرم را پر می‌کند؛ ساخت پروژه پس از تأیید کاربر است.
- ویرایش متن ایده روی همان شناسهٔ پروژه ذخیره می‌شود. تغییر نوع بازی درس‌ها و بوم را از آغاز تنظیم می‌کند؛ تغییر متن با حفظ نوع، پیشرفت را نگه می‌دارد. این رفتار پیش از ذخیره توضیح داده می‌شود.
- پالت فعلی، Vazirmatn، RTL، هوپی و تغییر تم حفظ شده‌اند. پیشنهادها دکمه‌های ساده و بدون پس‌زمینهٔ قرصی‌اند.

## داده و امنیت

خانه از داده‌های همان حساب در مسیر ذخیرهٔ موجود Supabase استفاده می‌کند؛ RPCها و RLS قبلی تغییر نکرده‌اند و مهاجرت دیتابیس جدید لازم نیست. پیش‌نویس فرم در مرورگر است؛ پروژه، مرحله و پیام‌های عضو با صف ذخیرهٔ موجود به حساب ابری وصل‌اند. خطای شبکه داده را موفق جلوه نمی‌دهد و امکان تلاش مجدد وجود دارد. کلید خصوصی یا credential جدیدی افزوده نشده است. مربی فعلی آموزش‌های ازپیش‌تعریف‌شده دارد و پرداخت واقعی همچنان فعال نیست.

## آزمون و بیلد

هر ۳۹ تست `npm test` موفق شد؛ صفر شکست و صفر مورد ردشده. `npm run build` با اتصال آنلاین حساب‌ها و `npm run prepare:pages` نیز موفق شدند.

تست جدید `tests/week6.test.mjs` دو سناریوی گسترده دارد: محاسبهٔ وضعیت واقعی و انتخاب پروژهٔ ناتمام؛ و جریان کامل انتخاب مسیر، فوکوس، اعتبارسنجی، ورود، ساخت، پیشرفت، ویرایش، خطای ذخیره/تلاش مجدد، تعویض نوع بازی، ادامه، قفل سهمیه و بازیابی پس از ورود. تست‌های قبلی برای تأیید صریح ایده و مقصد خانه پس از ورود به‌روزرسانی شدند. آزمون‌های دیتابیس محلی و Auth قبلی نیز در مجموعهٔ ۳۹تایی اجرا شدند؛ آزمون آنلاین حساب شخصی در این تحویل تکرار نشده است.

نمای دسکتاپ و موبایل ۳۷۵ پیکسل، تم روشن و تاریک، پنج مسیر و نبود سرریز افقی در مرورگر بررسی شدند. آزمون با کاربران جدید انجام نشده؛ ساده‌سازی بر اساس بازخورد مستقیم مالک دربارهٔ شلوغی انجام شده است.

## ساخت و انتشار

از پوشهٔ `SOURCE`:

```powershell
npm ci
npm test
npm run build
npm run prepare:pages
```

متغیرهای عمومی Supabase و `APP_BASE_PATH=/hplgame-webapp/` باید طبق README تنظیم باشند. workflow موجود روی main تست‌ها را اجرا می‌کند، بیلد می‌گیرد و artifact را در GitHub Pages مستقر می‌کند؛ استقرار به موفقیت تست وابسته است. برای Git دارای دسترسی مالک:

```powershell
git add SOURCE app.js index.html prototype.css
git commit -m "Build week 6 learning home and simplify navigation"
git push origin main
```

در این محیط Git با حساب دیگری مجوز push ندارد؛ انتشار از مرورگر متصل به حساب مالک انجام شد. نسخهٔ نهایی `25c3f8a` در ۲۷ نوامبر ۲۰۲۶ روی main منتشر شد؛ هر دو workflow «Verify HPLGAME source» و «Build and publish HPLGAME» موفق شدند. اسکریپت نسخهٔ زنده `app.js?v=8486706419b9` تأیید شد. در سایت زنده چهار مقصد ناوبری، پنج مسیر آموزشی، نبود نشان‌های تزئینی و سرریز افقی، تغییر تم و انتقال انتخاب پازل به فرم قابل ویرایش بررسی شدند. بررسی زندهٔ نسخهٔ نخست مسابقهٔ زمانی فوکوس را آشکار کرد؛ نسخهٔ نهایی فوکوس مقصد را پس از رندر مسیر اعمال می‌کند. تست یکپارچه بدون اجرای دستی فریم انیمیشن این رفتار را پوشش می‌دهد و هر ۳۹ تست پس از اصلاح دوباره موفق شدند. این بررسی پروژهٔ ابری جدید یا پرداختی ایجاد نکرد.
