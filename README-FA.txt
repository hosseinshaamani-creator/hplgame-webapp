HPLGAME — بسته آماده اجرا و آپلود

این بسته شامل تمام فایل‌های لازم سایت، فونت‌های فارسی و کتابخانه Supabase است.
برای انتشار نسخه آماده، npm یا build لازم نیست.

آپلود در GitHub Pages:
۱. فایل ZIP را از حالت فشرده خارج کن.
۲. index.html، app.js، styles.css، manifest.webmanifest، دو فایل فونت،
   فایل .nojekyll و پوشه chunks را در ریشه مخزن hplgame-webapp قرار بده.
۳. ساختار پوشه chunks را حفظ کن و اجازه بده فایل‌های جدید جای فایل‌های قبلی را بگیرند.
۴. در Settings → Pages، انتشار از شاخه main و پوشه / (root) را انتخاب کن.
۵. فایل ZIP را به‌عنوان تنها فایل سایت آپلود نکن؛ محتویات استخراج‌شده لازم‌اند.

اجرای محلی روی این کامپیوتر:
START-LOCAL.cmd را اجرا کن. Python باید نصب باشد.
سپس در مرورگر آدرس http://127.0.0.1:4182/ را باز کن.
پنجره سرور را تا پایان استفاده باز نگه دار.
به دلیل استفاده از ماژول JavaScript، index.html را با دوبار کلیک اجرا نکن؛
از سرور محلی یا GitHub Pages استفاده کن.

وضعیت حساب کاربری:
حالت مهمان آماده اجراست. ثبت‌نام و ذخیره آنلاین تا ایجاد و تنظیم Supabase
غیرفعال‌اند؛ با آپلود ZIP به‌تنهایی، دیتابیس یا سرویس احراز هویت ایجاد نمی‌شود.
پروژه مهمان فقط روی همان مرورگر ذخیره می‌شود.

سورس کامل نیز در پوشه SOURCE قرار دارد. این پوشه برای اجرای نسخه آماده لازم نیست.
برای تنظیم Supabase یا تغییر کد، راهنمای SOURCE/README.md را بخوان.
SQL و policyهای RLS در SOURCE/supabase/migrations قرار دارند.
فایل محیط نمونه SOURCE/.env.example است؛ هیچ رمز یا کلید خصوصی در بسته نیست.
